# העלאת גרסת ניסוי לפרויקט האמיתי

**מה זה עושה:** מעלה את האפליקציה לכתובת **https://ettunley-61749.web.app**, כדי שתוכלי לנסות אותה בעצמך מהטלפון והאייפד.

**כמה זמן:** כ-30 עד 45 דקות בפעם הראשונה.
**עלות:** בדרך כלל 0 ₪ (בתוך המכסה החינמית).
**מיילים:** בגרסת הניסוי לא נשלחים מיילים אמיתיים. אישור הורה במייל ייבדק בהמשך.

## מה צריך להיות מוכן

- ✓ חשבון חיוב פעיל (Blaze), והתראת תקציב.
- ✓ אימות דו-שלבי בחשבון Google שלך.
- ✓ כניסה לחשבון GitHub שבו נמצא המאגר.

## צעד 1: הורדת הקוד מ-GitHub

1. באייפד, פתחי בדפדפן (כשאת מחוברת ל-GitHub) את הקישור:

   `https://github.com/hodiadmri-oss/Ettunley/archive/refs/heads/claude/start-execution-7ckvh4.zip`

2. הקובץ יורד (שם הקובץ: `Ettunley-claude-start-execution-7ckvh4.zip`). הוא נשמר באפליקציית **קבצים** באייפד, בתיקיית ההורדות.

## צעד 2: פתיחת Cloud Shell והעלאת הקובץ

1. פתחי **https://shell.cloud.google.com** (באותו חשבון Google של הפרויקט). אשרי תנאים אם מבקשים. יפתח מסוף בתחתית המסך.
2. לחצי על **שלוש הנקודות ⋮** בפינת המסוף (או על תפריט ה-"More") ובחרי **Upload**.
3. בחרי את קובץ ה-ZIP מהאייפד. ממתינים עד שמופיע שהקובץ הועלה.

## צעד 3: הכנה והרצה

1. הדביקי ולחצי Enter:

   ```
   unzip -q Ettunley-claude-start-execution-7ckvh4.zip && cd Ettunley-claude-start-execution-7ckvh4
   ```

2. עכשיו:

   ```
   bash scripts/deploy-trial.sh
   ```

3. הסקריפט יסביר מה הוא עושה וישאל. כתבי **yes** ולחצי Enter.
4. **התחברות ל-Firebase:** יופיע קישור. פתחי אותו (לחיצה ארוכה ← "Open"), התחברי עם חשבון ה-Google שלך, אשרי, והעתיקי את הקוד שמוצג. הדביקי אותו בחזרה במסוף.
5. **ייתכן שיישאל** אם לתת ל-Storage הרשאה לקרוא מ-Firestore. ענו **Y**. כללי הקבצים צריכים את זה.
6. ממתינים. ההתקנה וההעלאה לוקחות כמה דקות. בסוף מוצגת הכתובת.

אם הסקריפט נעצר עם `ERROR`, **צלמי את המסך ושלחי לי.** זה מצופה שאולי נצטרך לתקן משהו בפעם הראשונה, כי זו הפעם הראשונה שאנחנו מנסים את זה על הפרויקט האמיתי.

> **הערה (מניסיון ההעלאה הראשונה):** Google מגבילה כמה פונקציות אפשר ליצור בדקה, ולכן העלאה גדולה אחת נכשלה חלקית. הסקריפט מעלה עכשיו את הפונקציות בקבוצות קטנות, ומנסה שוב במקרה הצורך. אם עדיין מופיעה שגיאה, מריצים את הסקריפט שוב (הקבוצות שהסתיימו עוברות מהר).

## צעד 4: הגדרת עצמך כמנהלת

1. פתחי **https://ettunley-61749.web.app** באייפד.
2. לחצי **כניסה** ← **כניסה עם Google**, והתחברי. יופיע מסך "מי את/ה?". **לא בוחרים כלום**, לוחצים **יציאה**.
3. חזרה ל-Cloud Shell, באותה תיקייה, הריצי (במקום the-email כתבי את כתובת ה-Gmail שלך):

   ```
   node scripts/set-admin.mjs the-email@gmail.com
   ```

   אם הצליח, תראי: `Done: ... is now the admin.`
4. באפליקציה: יציאה וכניסה שוב עם Google. תגיעי לדף **ניהול**.

(ההסבר המורחב נמצא ב-`docs/ADMIN-SETUP.md`.)

## צעד 5: ניסוי

אם הגעת לדף הניהול, הכול עובד. כמה דברים לנסות:

1. פתחי חלון **גלישה בסתר** או דפדפן אחר, והירשמי כ**מורה** עם חשבון Google אחר (או חשבון בדיקה). אשרי את ההצהרה.
2. בדף הניהול: אשרי את המורה.
3. בחלון נוסף: הירשמי כ**תלמיד/ה** עם אימייל וסיסמה, מלאי את הפרטים, והקלידי את הקוד של המורה.
4. כמורה: אשרי את התלמיד/ה.

מה לבדוק בזמן הניסוי: איך זה נראה בפועל בטלפון, אם חלון ה-Google עובד באייפד, וכל דבר שמרגיש לא נוח.

## לעצור או למחוק

  ```
  npx firebase hosting:disable --project ettunley-61749
  ```
